# 토닥토닥 — 공통 화면 라이팅 가이드

> 대상: **신별 페르소나가 개입하지 않는 서비스 공통 화면**(01·02·04·05·06·07·09·11·12·13·예외 3종).
> 08 상담 결과·10 나만의 부적의 본문은 신별 페르소나 영역이라 이 가이드가 아니라
> `docs/신별_동적화_설계.md`의 신별 화법을 따른다.
> 방법: 현재 문구를 전수 추출(133개) → 규칙 도출 → 어긋난 것 수정. 문구가 먼저, 규칙은 그 다음.

## 1. 목소리 (Voice)

서비스는 **곁에 있는 조력자**다. 판정하지 않고, 재촉하지 않고, 대신 결정하지 않는다.

| 지향 | 회피 |
|---|---|
| 오늘 하나만 하자고 제안 | 삶을 바꾸라는 조언 |
| 사용자가 이미 한 일을 인정 | 부족함을 지적 |
| 선택지를 보여주고 맡김 | 정답을 단정 |
| 안 해도 괜찮다고 먼저 말함 | 완수를 압박 |

**핵심 문형**: "~해도 괜찮아요" · "~하지 않아도 돼요" · "~할 수 있어요"
현행 문구에서 이 형태가 반복 등장하며 서비스 톤을 만든다 — 유지할 것.
> "짧게 적어도 괜찮아요. 한 문장이어도 충분해요." · "무리하게 바꾸라는 말은 하지 않아요."

## 2. 어조 (Tone) — 확정 규칙

1. **해요체로 통일.** 합쇼체(–습니다/–ㅂ니다)·반말 금지. *(신별 화면은 예외 — 신마다 고유 화법)*
2. **버튼은 "~하기" 행동명.** 명사 단독(확인·완료)이나 명령형(입력하세요) 금지.
   - ✓ `고민부터 시작하기` `결과 받아보기` `저장하기` `부적 공유하기`
   - ✗ `확인` `제출` `시작`
3. **질문형 타이틀**로 화면을 연다. 사용자가 답할 준비를 하게 만든다.
   - `오늘 마음에 걸리는 일이 있나요?` `오늘은 어느 정도까지 괜찮을까요?` `오늘 결과는 어땠나요?`
4. **2인칭 호칭 생략.** "당신은/여러분" 대신 주어 없이. *(신별 화면에서는 신이 "당신/너"를 씀 — 그건 페르소나 영역)*
5. **한 문장 = 한 정보.** 두 줄 이상이면 `<br>`로 의미 단위 끊기.
6. **느낌표·이모지 금지.** 감정은 어휘로. (UI 아이콘 이모지도 금지 — 룰셋 anti-tell)
7. **말줄임표(…) 대신 마침표.** 로딩 문구도 "~하고 있어요."로 끝맺는다.

## 3. 화면 유형별 패턴

| 유형 | 타이틀 | 서브 | 예시 |
|---|---|---|---|
| **입력 요청** | 질문 또는 청유 | 부담 낮추는 안심 문구 | `지금 마음에 남아 있는 말을 편하게 적어주세요` + `짧게 적어도 괜찮아요.` |
| **선택 제시** | 질문 | 고르는 기준 안내 | `어떤 토착신에게 고민을 건네볼까요?` + `무엇을 기준으로 고르면 좋을지 먼저 보여드릴게요.` |
| **대기(로딩)** | 지금 일어나는 일 (현재진행) | 무엇을 하는 중인지 구체적으로 | `토착신이 지금 마음의 결을 살펴보고 있어요` |
| **확인** | 무엇이 어떻게 반영되는지 | 항목별 `→` 로 결과 연결 | `→ '지금 마음의 결'에 반영돼요.` |
| **완료/공유** | 준비됐음을 알림 | 무엇이 포함/미포함인지 | `저장할 이미지가 준비됐어요` + `고민 원문은 포함하지 않고,` |
| **피드백 요청** | 질문 | 부담 낮추기 | `먼저 가볍게만 알려주세요.` |
| **예외** | 상황을 사용자 탓으로 돌리지 않는 서술 | 다음 행동 제시 | `결과를 만드는 데 시간이 조금 더 걸리고 있어요` |

## 4. 안전·신뢰 문구 (필수 · 임의 수정 금지)

이 서비스는 점술이 아니라 정리 도구임을 반복해 밝힌다. 아래 취지는 반드시 유지:

- **면책(01)**: `미래를 맞히거나 결정을 대신하는 서비스가 아니라, 오늘의 고민을 정리하기 위한 참고예요.`
- **부적 면책(10)**: `어떤 일을 반드시 이루게 하는 약속이 아니라, 오늘의 마음과 작은 실천을 기억하기 위한 상징이에요.`
- **개인정보(04)**: `실명, 연락처, 주소는 적지 않아도 괜찮아요.`
- **공유 범위(11)**: `고민 원문은 포함하지 않고, 부적과 오늘의 문장만 담았어요.`
- **위기(예외 안전)**: 판단·진단하지 않고 전문 기관 연결. `지금 혼자 버티지 말고 가까운 사람이나 전문 기관의 도움을 받아주세요.`

## 5. 용어 통일

| 쓴다 | 안 쓴다 |
|---|---|
| 토착신 | 신령·캐릭터·AI |
| 고민 | 사연·상담 신청·문의 |
| 작은 실천 | 미션·과제·처방·할 일 |
| 부적 | 카드·결과물·굿즈 |
| 상담 결과 | 진단·분석·리포트 |
| 마음의 결 | 심리 상태·감정 분석 |

## 6. 발견된 불일치 (수정 대상)

전수 점검에서 나온 규칙 위반. **[수정 완료]** 표시가 없는 항목은 결정 대기.

- **[수정 완료] 예외 실패 화면 어조 혼용** — 같은 화면에서 해요체와 합쇼체가 섞여 있었다.
  - 기존: `입력한 고민은 유지됩니다.` (합쇼체)
  - 수정: `입력한 고민은 그대로 있어요.` → §2-1 위반 해소
- **[수정 완료] 04 하단 안내가 신 선택 진입과 어긋남** — 한 문구로 두 경로를 다 덮고 있었다.
  - 공통 입력: `고민부터 시작했든, 토착신을 먼저 골랐든 여기서부터는 같은 방식으로 진행돼요.` (유지)
  - 신을 고른 경우: `적은 고민은 <b>○○</b>이 읽어요. 언제든 다른 신으로 바꿀 수 있어요.`
  → 이미 정해진 걸 알려주고(§1 인정), 되돌릴 수 있음을 먼저 말한다(§1 "맡김"). 조사는 `josa()`.
- **검토 필요: 05·06 버튼 라벨** `다음 단계`는 §2-2의 "~하기" 규칙에서 벗어난 명사형.
  `다음 단계로` 또는 `계속하기`로 통일할지 결정 필요. (현재 피그마 디자인 원문 유지 중)
- **[수정 완료] 10 하단 버튼 3개** — '오늘의 상담 결과' 카드를 없애고 버튼으로 내렸다.
  `저장/공유하기`(주) · `새로운 고민 상담하기` · `상담 결과 다시 보기`(보조 2).
  '다시'가 있어야 이미 본 화면으로 되돌아간다는 게 읽힌다 — 되돌아가기는 '다시'를 붙인다.
- **신 선택 시트 머리말**(04) — `어떤 신의 의견을 들어볼까요?` + `고민의 결에 따라 잘 맞는 신이
  달라요. 고르면 그 신이 이 고민을 봐요.` §3 "선택 제시"(질문 + 고르는 기준) 패턴을 따른다.

## 7. 체크리스트 (문구 작성·리뷰 시)

- [ ] 해요체인가 (신별 화면 제외)
- [ ] 버튼이 "~하기" 행동명인가
- [ ] 타이틀이 질문 또는 청유인가
- [ ] 사용자를 탓하거나 재촉하지 않는가
- [ ] 느낌표·이모지·말줄임표가 없는가
- [ ] 용어표(§5)를 따랐는가
- [ ] 안전·면책 문구(§4)의 취지가 훼손되지 않았는가
- [ ] 두 줄 이상이면 의미 단위로 `<br>` 했는가
