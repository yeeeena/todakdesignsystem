# 토닥토닥 — 시각 검증 체크리스트

새 화면·수정 화면은 아래를 통과해야 한다. (/ss-score · /ss-verify 게이트 입력)

## 필수 tell (있어야 함)

- [ ] 캔버스 390×844 · 본문 좌우 24px · 8px 그리드
- [ ] 페이지당 주 CTA 1개 — charcoal 채움 52px r12, 라벨 "~하기" 해요체
- [ ] 카드: surface + 1px ink-08 + r16 + pad 18 (딥컬러 배경 위에서는 2px charcoal 테두리 rcard)
- [ ] 위계는 잉크 불투명도(83/82/40)와 굵기로 — 유채색으로 위계 만들지 않음
- [ ] letter-spacing ≤0 · 다크 배경 타이틀은 keep-all · 조사(이/가)는 josa()
- [ ] 몰입 화면(01·02·04–06·08·11)은 풀블리드 일러스트 + 코드 레이어 텍스트
- [ ] 신별 딥컬러는 deityResult.bg 6종만 사용, 화면 배경 전용
- [ ] 하단 넘침 화면은 sticky 푸터 + 배경색(또는 투명→색 그라디언트)
- [ ] 로딩 = 캐릭터 링 로더(링 채움 + 아바타 순환) · 진행 = step-hud(180×6, 트랙 #4d515c) — 3-dot·스켈레톤 금지
- [ ] 모든 모션 prefers-reduced-motion 대응 · UI 전환 ≤320ms(플립 640 예외)
- [ ] 신규 자산 명명: 영문 key + @배수x · 투명 필요 컷은 PNG 알파 · 실루엣 인터랙션은 SVG 마스크(+6px 팽창)

## 금지 anti-tell (있으면 실패)

- [ ] 순검정 #000 · 이모지를 UI 아이콘으로 사용
- [ ] 스켈레톤 시머 · 무한 회전 스피너
- [ ] 신별 딥컬러/키컬러를 버튼·텍스트·작은 요소에 사용
- [ ] 무지개 상태색 (critical/warning은 안전·실패 화면 전용)
- [ ] 하단 탭바 (검토 후 보류 결정 — 2026-08-01)
- [ ] uppercase 오버라인 라벨 · 양수 자간
- [ ] 하드섀도를 랜딩 btn-pill 외부로 확산
- [ ] 카드 패딩 <14px 의 촘촘한 밀도
- [ ] 캐릭터 컷을 불투명 사각형으로 배치(배경 겹침 티남 — 반드시 투명 PNG/마스크)
- [ ] `<button>`에 `color` 미지정(브라우저 기본 #000 상속) — 커스텀 버튼은 `--text-primary` 명시
- [ ] 문자 글리프(✕ ›)를 아이콘으로 사용 — 뒤로/닫기/셰브런은 24px stroke 1.8 SVG

## 회귀 시나리오 (수정 시 재확인)

1. **02 신단 팝**: 캐릭터 탭 → 1.06 팝(280ms) → 뒤 원본이 비치지 않음 → 150ms 후 시트. 마스크 6px 팽창 유지.
2. **08 빼꼼 겹침**: result-peek 하단이 첫 rcard 위로 정확히 9px 겹침 (6신 공통).
3. **08·11 sticky 푸터**: 스크롤 0/중간/끝 모두 하단 밀착 · 배경이 콘텐츠 끝까지(cover).
4. **10 플립**: 카드(316×498)가 하단 바에 가리지 않음(간격 ≥0) · 진입 peek 1회.
5. **11 카드 클립**: share-card r16 — 모서리 크림색 비침 없음.
6. **04–06 아트**: 신별 세트는 **02 신단 진입(`deityEntry`)에서만**. 공통 입력으로 들어와
   04에서 신을 바꿔도 04·05·06 모두 common 유지. 시트 상단은 `top:93.333cqw`(폭 비례) —
   화면 높이 기준으로 되돌리면 일러스트와의 겹침이 어긋난다.
7. **다크 화면 텍스트**: surface/offwhite 사용, 대비 4.5:1 이상 (rgba(255,253,252,.8) 이하 금지 본문).
8. **단일 파일 번들**: 빌드 후 /assets/ 네트워크 요청 0건 · 한글 파일명 NFC 매칭.
9. **번들 시트**: 빌드 후 02 신단 → 캐릭터 탭 → '○○에게 고민 말하기'가 실제로 04로 넘어가는지.
   시트를 연 뒤 innerHTML을 다시 쓰면 핸들러가 날아가 버튼이 죽는다(2026-08-02 회귀).

## 문구 — 화면에 물린 것만 (문체·용어 정본은 라이팅 가이드)

목소리·어조·용어표는 라이팅 문서가 정본이다. 여기서는 **화면 구조와 짝지어져 있어
디자인 리뷰에서 같이 봐야 하는 것**만 확인한다.

**필수 문구 — 취지가 유지돼야 함 (임의 삭제·약화 금지)**

| 화면 | 무엇을 밝히는가 |
|---|---|
| 01 시작 | 점술이 아니라 정리 도구 — `미래를 맞히거나 결정을 대신하는 서비스가 아니라…` |
| 04 입력 | 개인정보 — `실명, 연락처, 주소는 적지 않아도 괜찮아요.` |
| 10 부적 | 부적 면책 — `어떤 일을 반드시 이루게 하는 약속이 아니라…` |
| 11 공유 | 공유 범위 — `고민 원문은 포함하지 않고, 부적과 오늘의 문장만 담았어요.` |
| 예외 안전 | 판단·진단하지 않고 전문 기관 연결 |
