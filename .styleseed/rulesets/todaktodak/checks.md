# 검증 체크리스트

화면을 만들거나 고친 뒤 이 목록으로 점검한다. 항목은 docs/design-guide/DESIGN.md 와 주제별 문서의 규칙에서 나왔다.

* [목차](./INDEX.md)

---

## 있어야 하는 것

* 캔버스는 phone-w(390) 폭이고, 본문 좌우 여백은 spacing-24 다.
* 360 폭에서도 글자가 넘치거나 겹치지 않는다.
* 간격은 spacing 척도 안의 값이다.
* 주 행동 버튼은 화면당 하나이고 차콜로 채웠다. 시작 화면(01)의 두 진입 버튼만 예외다.
* 카드는 표면 색, 1px stroke-neutral 테두리, r-xl 반경, spacing-18 안쪽 여백이다. 딥컬러 배경 위의 결과 카드만 2px 차콜 테두리다.
* 글자 위계는 fg-neutral, fg-neutral-muted, fg-neutral-subtle 로 나눴다.
* 자간은 0 이하다. 어두운 배경의 제목과 좁은 폭의 이름은 어절 중간에서 끊기지 않는다.
* 신 이름 뒤 조사(이, 가)는 받침에 따라 자동으로 고른다.
* 몰입 화면(01, 02, 04~06, 08, 11)은 뒤에 일러스트, 앞에 코드로 만든 텍스트다.
* 신별 딥컬러는 배경에만 썼다.
* 콘텐츠가 넘치는 화면은 하단 행동 영역이 고정돼 있다.
* 기다리는 화면은 캐릭터 링 로더를 쓰고, 고민 정리의 단계 표시는 일러스트 위 진행 막대다.
* 새로 넣은 움직임은 움직임 줄이기 설정에서 멈춘다. 지금은 로더의 링, 부적 뒤집기, 신단 팝 세 곳만 대응돼 있고 로더 아바타 순환은 계속된다.
* UI 전환은 motion 의 느림 단계를 넘지 않는다. 부적 뒤집기만 예외다.
* 새 그림 파일은 영문 신 이름과 배율로 이름 짓는다. 겹치는 캐릭터는 투명 PNG, 실루엣대로 반응하는 그림은 SVG 마스크로 만든다.

## 없어야 하는 것

* 순검정, 이모지 아이콘, 문자 기호 아이콘(✕, ›). 뒤로와 닫기, 셰브런은 SVG 선 아이콘이다.
* 스켈레톤과 무한 회전 스피너.
* 배경 밖에 쓴 신별 딥컬러, 신 비교 목록에 쓴 신별 색.
* 안전 안내와 생성 실패 밖에 쓴 위험·경고 색.
* 하단 탭바(2026-08-01 결정).
* 대문자 오버라인과 양수 자간.
* 시작 화면 버튼 밖으로 번진 하드 섀도.
* 안쪽 여백이 14보다 좁은 카드.
* 불투명한 사각형으로 놓인 캐릭터 컷. 배경과 겹친 티가 난다.
* 글자색을 지정하지 않은 버튼. 브라우저 기본값이 순검정이다.
* 새로 쓴 옛 별칭 토큰(grey, blue, text 계열).

## 고친 뒤 다시 확인할 것

* 신단(02): 캐릭터를 누르면 실루엣대로 살짝 커지고, 뒤 캐릭터가 비치지 않고, 잠시 뒤 시트가 열린다.
* 상담 결과(08): 캐릭터가 첫 카드 위로 여섯 신 모두 같은 만큼 겹친다.
* 상담 결과와 저장/공유(08, 11): 스크롤 처음, 중간, 끝에서 하단 영역이 붙어 있고 배경이 끝까지 채워진다.
* 나만의 부적(10): 카드가 하단 영역에 가리지 않고, 뒤집기 힌트는 진입할 때 한 번만 나온다.
* 저장/공유(11): 부적 카드 모서리에 크림색이 비치지 않는다.
* 고민 정리(04~06): 신단(02)에서 들어왔을 때만 신별 일러스트가 나오고, 이때 입력 화면에서 신을 바꾸면 새 신의 일러스트로 바뀐다. 고민부터 들어왔다면 신을 바꿔도 공통이 유지된다. 시트 상단 위치는 폭에 비례한다.
* 어두운 배경의 흰 글자: 기준은 아직 정하지 않았다. 바꿨다면 여섯 신 배경 위 대비를 재서 확인사항에 남긴다.
* 공유용 단일 파일을 다시 만들었다면: 이미지 요청이 밖으로 나가지 않고 한글 이름의 이미지도 열린다. 신단에서 신을 골라 고민 입력으로 넘어가는 버튼이 실제로 동작한다. 2026-08-02에 시트를 다시 그리다가 이 버튼이 죽은 적이 있다.

## 문구가 붙는 자리

문구의 정본은 Copy Master다. 이 목록은 문구를 인용하지 않고, 고지가 붙을 자리가 남아 있는지만 본다. 실제 문구는 copy_id 로 찾는다.

Copy Master에서 안전 검토 대상으로 잠긴 문구(safety_locked)는 19건이다. 디자인을 고칠 때 그 자리를 없애거나 스크롤 밖으로 밀지 않는다.

* 시작(01) 하단 안내: landing.caption.disclaimer
* 고민 입력(04) 입력창 아래 개인정보 안내: input.helper.privacy_notice
* 나만의 부적(10) 하단 과몰입 방지 안내: talisman.caption.disclaimer
* 저장/공유(11) 설명과 저장 완료 토스트: share.hero.body.description, share.toast.saved
* 안전 안내(14): 화면 전체 7건. safe 로 시작하는 copy_id 다.
* 내부 요청 안내(15): 화면 전체 7건. asset 으로 시작하는 copy_id 다.

14와 15는 화면 전체가 잠겨 있다. 배치만 바꾸고 문구의 구조를 다시 짜지 않는다.

그 밖에 확인할 것이 있다.

* 새 문구가 필요하면 디자인 문서에 쓰지 않고 Copy Master에 제안했다.
* 버튼 라벨은 행동을 말하는 형태다.
* 고민부터 온 길과 신부터 온 길에서 고민 입력(04)의 신 추천과 하단 안내가 맞게 바뀐다.
* 상담 결과와 나만의 부적(08, 10)의 본문은 공통 규칙이 아니라 신별 화법을 따른다.
* 이름이 들어가는 자리를 가장 긴 신 이름(삼신할미)으로 확인했다.
