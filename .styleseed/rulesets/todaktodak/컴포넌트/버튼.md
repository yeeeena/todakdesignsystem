# 버튼

사용자가 실행할 행동을 표현한다.

* [컴포넌트 목록](../카테고리/컴포넌트.md)

---

주 버튼은 차콜로 채운다. 높이는 52px, 반경은 r-m 이다. 화면당 하나만 둔다. 혼자 놓이면 라벨은 button-lg, 다른 버튼과 나란히 놓이면 button-md 를 쓴다.

보조 버튼은 표면 색에 stroke-neutral-strong 테두리를 두르고, 크기는 주 버튼과 같다. 되돌아가기와 다른 선택지에 쓴다.

고스트 버튼은 배경 없이 높이 40px, 반경 r-s 로 둔다. 주 버튼과 보조 버튼보다 가벼운 행동에 쓴다. 지금은 오늘 가능한 정도(05)의 결과로 바로 가기, 생성 실패(16)의 처음으로 돌아가기, 신 소개 시트의 자세히 보기에 있다.

하단 행동 영역에서는 버튼 두 개를 같은 폭으로 나란히 둔다. 토착신 상세(03)와 신 소개 시트는 주 버튼 아래에 다른 버튼을 세로로 쌓는다. 세 개가 필요하면 주 행동 하나를 전폭으로 위에, 보조 둘을 한 줄로 아래에 둔다. 나만의 부적(10)과 저장/공유(11)가 그렇다. 같은 위계 세 개를 한 줄에 늘어놓지 않는다.

아이콘 버튼은 40px 정사각형, 반경 r-m 이고 안에 24px SVG 아이콘을 둔다. 뒤로와 닫기에 쓴다.

텍스트 링크는 밑줄을 긋는다. 딥컬러 배경 위에서는 흰색으로 쓴다.

두 가지는 한 화면 전용이다. 시작 화면 버튼은 차콜 테두리와 하드 섀도를 쓰고 누르면 살짝 밀린다. 시작 화면은 이 버튼 두 개를 같은 위계로 나란히 두며, 주 행동 하나 규칙의 예외다(2026-09-19 결정). 저장/공유 화면의 버튼은 반경 r-l 에 크기가 조금 다르다. 다른 화면에서 쓰지 않는다.

코드 클래스: btn 에 btn-primary, btn-secondary, btn-ghost 를 더한다. 높이 52px은 btn-xl 과 btn-l 인데 둘은 값이 같다. 고스트는 btn-m, 나란히 두기는 btn-row 와 bb-btns, 세 개 쌓기는 bb-stack, 시작 화면은 btn-pill, 저장/공유는 share-save 와 share-sub, 텍스트 링크는 landing-link 와 result-link, 아이콘 버튼은 icon-btn 이다.
