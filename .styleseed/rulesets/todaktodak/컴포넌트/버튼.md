# 버튼

사용자가 실행할 행동을 표현한다.

* [컴포넌트 목록](../카테고리/컴포넌트.md)

---

주 버튼은 차콜로 채운다. 높이는 52px, 반경은 r-m 이다. 화면당 하나만 둔다. 혼자 놓이면 라벨은 button-lg, 다른 버튼과 나란히 놓이면 button-md 를 쓴다.

보조 버튼은 표면 색에 stroke-neutral-strong 테두리를 두르고, 크기는 주 버튼과 같다. 되돌아가기와 다른 선택지에 쓴다.

고스트 버튼은 배경 없이 높이 40px, 반경 r-s 로 둔다. 바로 결과 보기처럼 흐름을 건너뛰는 세 번째 행동에 쓴다.

버튼 두 개는 같은 폭으로 나란히 둔다. 세 개가 필요하면 주 행동 하나를 전폭으로 위에, 보조 둘을 한 줄로 아래에 둔다. 나만의 부적(10)과 저장/공유(11)가 그렇다. 같은 위계 세 개를 한 줄에 늘어놓지 않는다.

아이콘 버튼은 40px 정사각형, 반경 r-m 이고 안에 24px SVG 아이콘을 둔다. 뒤로와 닫기에 쓴다.

텍스트 링크는 밑줄을 긋는다. 딥컬러 배경 위에서는 흰색으로 쓴다.

두 가지는 한 화면 전용이다. 시작 화면 버튼은 차콜 테두리와 하드 섀도를 쓰고 누르면 살짝 밀린다. 저장/공유 화면의 버튼은 반경 r-l 에 크기가 조금 다르다. 다른 화면에서 쓰지 않는다.
