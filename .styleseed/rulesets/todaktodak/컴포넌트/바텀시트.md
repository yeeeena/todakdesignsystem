# 바텀시트

화면 위로 올라오거나 화면 아래를 차지하는 시트다.

* [컴포넌트 목록](../카테고리/컴포넌트.md)

---

시트는 두 종류다.

전역 시트는 어느 화면에서든 위로 밀려 올라온다. 상단 반경은 r-3xl 이고 화면 높이의 76%를 넘지 않는다. 뒤에 베일이 깔리고, 베일을 누르면 닫힌다.

전역 시트에는 두 가지 내용이 들어간다. 신 소개 시트는 큰 신 아이콘과 이름, 역할, 잘 맞는 고민, 말투 미리보기, 많이 건네는 고민 카드, 버튼 두 개를 담는다. 신 선택 시트는 여섯 신을 카드 목록으로 보여준다.

신 선택 목록의 항목은 카드 문법을 그대로 쓴다. 이름은 신별 색이 아니라 차콜로 쓴다. 지금 추천하는 신만 차콜 테두리와 옅은 틴트, 지금 추천 배지로 표시한다. 다른 신을 고르면 적던 고민 글과 고른 칩을 그대로 둔다. 상단 일러스트는 고민부터 들어온 경우 공통을 유지하고, 신단(02)에서 들어온 경우 새 신의 그림으로 바뀐다.

고민 정리 시트는 04~06 화면의 아래를 차지한다. 상단 반경은 r-2xl 이고, 상단 위치는 화면 폭에 비례한다. 안쪽은 따로 스크롤되고, 맨 아래 버튼 영역은 고정된 채 위쪽에 얇은 구분선을 둔다.

코드 클래스: 전역 시트는 sheet 와 sheet-veil, 머리는 sheet-grab, sheet-head, sheet-name, sheet-role 이다. 신 선택 목록은 picker-list, picker-item(추천 신은 current), picker-body, picker-name, picker-fit, picker-go 다. 고민 정리 시트는 sheet-panel, sheet-scroll, sheet-foot 이다.
