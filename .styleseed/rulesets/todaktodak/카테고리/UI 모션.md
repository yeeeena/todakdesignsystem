# UI 모션

화면과 상태가 바뀔 때의 움직임을 정의한다.

* [목차](../INDEX.md)

---

전환 시간은 motion 토큰의 세 단계(빠름, 기본, 느림)에서 고른다. UI 전환은 느림 단계를 넘기지 않는다. 부적 카드를 뒤집는 동작만 예외로 더 길다.

바텀시트는 아래에서 밀려 올라오고, 뒤의 베일은 조금 더 빨리 나타난다.

버튼을 누르면 막이 짧게 덮인다. 시작 화면 버튼만 눌린 쪽으로 살짝 밀린다.

움직임 줄이기 설정을 켠 사용자에게는 로더 링, 부적 뒤집기, 신단 캐릭터 팝이 멈춘다. 시트 전환 같은 나머지 움직임은 아직 대응하지 않았다.

그림 자체의 움직임은 [애니메이션](./애니메이션.md)에서 다룬다.
