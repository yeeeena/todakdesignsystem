# 아이콘

기능을 나타내는 기호의 모양과 크기를 정의한다.

* [목차](../INDEX.md)

---

뒤로, 닫기, 셰브런은 SVG 선 아이콘으로 통일한다. 선 굵기는 1.8이고, 색은 부모 글자색을 따른다. 기본 색은 fg-neutral-secondary 다(2026-09-25 결정).

아이콘 버튼 안의 아이콘은 24px, 목록 항목 끝의 셰브런은 20px다.

문자 기호(✕, › 같은 것)나 이모지를 아이콘 대신 쓰지 않는다. 폰트에 따라 굵기와 정렬이 달라지기 때문이다.

체크리스트와 토스트의 완료 표시만 아직 문자 ✓ 를 쓴다. SVG로 바꿀지는 정하지 않았다.

아이콘 버튼의 접근 가능한 이름은 [접근성](./접근성.md)에서 다룬다.
