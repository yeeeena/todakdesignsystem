# UI 상태 체계

요소가 눌림, 선택, 포커스, 비활성일 때의 모습을 정의한다.

* [목차](../INDEX.md)

---

눌림은 짧게 덮이는 막으로 표시한다. 밝은 요소에는 어두운 막, 어두운 요소에는 밝은 막을 쓴다.

선택은 차콜로 표시한다. 칩은 차콜로 채우고 글자를 굵게 한다. 점수와 신 선택 목록은 차콜 테두리와 옅은 틴트를 쓴다. 선택 상태에 유채색을 쓰지 않는다.

비활성 요소는 흐리게 낮춘다.

포커스 표시는 입력창에만 있다. 입력창은 포커스를 받으면 테두리가 굵어진다. 다른 요소의 포커스 표시는 아직 정의하지 않았다.

모바일 화면이라 마우스 호버 상태는 두지 않는다.
