# 디자인 원칙

화면을 판단할 때 먼저 따르는 원칙을 정의한다.

* [목차](../INDEX.md)

---

흐름은 선형이다. 한 화면에서 사용자가 내리는 결정은 하나이고, 주 행동 버튼도 하나다. 여러 선택지를 대시보드처럼 펼치지 않는다. 시작 화면(01)만 예외로, 두 진입 버튼을 같은 위계로 둔다(2026-09-19 결정).

코드와 디자인 문서가 다르면 화면 구성과 흐름은 코드를, 토큰과 스타일은 문서를 따르고, 차이를 보고한다(2026-09-19 결정).

진입은 두 갈래다. 고민을 먼저 적는 길과 신을 먼저 고르는 길이 있고, 두 길은 고민 입력 화면(04)에서 합류한다. 어느 길로 들어왔는지는 화면에 남아 고민 정리 단계의 일러스트, 뒤로 가기 목적지, 신 추천이 보이는 시점을 바꾼다.

이 서비스는 점술이 아니라 오늘의 고민을 정리하는 도구다. 그래서 면책과 개인정보, 공유 범위를 밝히는 고지가 정해진 화면에 붙는다. 디자인을 바꿔도 그 자리를 없애지 않는다. 문구 자체는 Copy Master가 정한다.

문서에 없는 판단은 일반적인 패턴으로 채우지 않는다. 멈추고 먼저 묻는다.
