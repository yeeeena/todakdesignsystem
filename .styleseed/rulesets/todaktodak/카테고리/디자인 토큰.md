# 디자인 토큰

토큰의 층과 값이 있는 곳을 정의한다.

* [목차](../INDEX.md)

---

값의 정본은 docs/design-guide/DESIGN.md 의 frontmatter다. docs/design-guide/tokens.json 은 같은 값을 담은 사본이라 한쪽만 고치지 않는다. 실제 코드에서는 prototype/todaktodak-working.html 의 :root 가 값을 정의한다.

색은 원시 값(atomic)과 SEED 역할 토큰(semantic) 두 층이다. SEED 이름은 외부 표준이라 바꾸지 않는다. 새 코드는 역할 토큰만 쓴다.

두 층이 끊기는 자리가 코드에 있다. 위험과 경고 색, 눌린 막, 베일, 눌린 주 버튼 면은 역할 토큰이 값을 직접 들고 있고 대응하는 원시 이름이 없다. Figma에서는 2026-09-25에 원시 색 열 개(red, red-deep, orange, red-weak, orange-weak, charcoal-pressed, black/56, black/26, black/06, offwhite/16)를 만들어 역할 토큰이 그것을 가리키게 했다. 코드에도 같은 이름을 둘지는 확인사항에 있다.

신별 색은 CSS 변수가 아니라 코드의 신별 데이터에 있다. 화면에는 --dbg 와 --dlabel 로 주입된다.

옛 별칭은 처음 토스 디자인 시스템 이름으로 만들었다가 SEED로 옮기면서 남은 이름들이다. 2026-09-19에 31개 중 25개를 지우고, 쓰이던 곳은 값이 같은 역할 토큰으로 바꿨다. 남은 여섯 개(grey-800, grey-400, grey-300, grey-200, fg-quaternary, border-secondary)는 83% 잉크 병합, placeholder 토큰 같은 판단이 끝나야 정리할 수 있다. 정리안은 docs/design-guide/TOKEN-MAPPING.draft.md 에 있다.

간격 토큰은 2026-09-19에 새로 정해 :root 에 넣었다. 쓰는 방법은 [간격 체계](./간격%20체계.md)를 따른다.
