# 토닥토닥 디자인 가이드 — 전달 패키지

토착신 AI 고민 처방 서비스 **토닥토닥**의 디자인 자료 묶음입니다.

## 👉 `DESIGN.md`부터 읽어주세요

**`DESIGN.md`가 이 패키지의 진입점입니다.** 현재 디자인 방향·토큰·컴포넌트 기준과
**무엇이 현재 기준이고 무엇이 참고·히스토리 자료인지**가 거기 정리돼 있습니다.
이 README는 패키지를 여는 방법만 다룹니다.

## 3분 안에 감 잡기

1. **`DESIGN.md`** §0(무엇을 기준으로 삼는가) → §1(핵심 원칙)
2. **`reference-board.html`** 브라우저로 열기 → 토큰·컴포넌트·일러스트 자산 72종을 한눈에
3. **`FOLLOWUP.md`** → 기존 파일에서 아직 손봐야 할 것

## 자료의 3단 구분 (중요)

| 구분 | 파일 |
|---|---|
| 🟢 **현재 기준** | `DESIGN.md` · `RULESET.md` · `COMPONENTS.md` · `tokens.json` · `checks.md` · `reference-board.html` · `토닥토닥_프로토타입_단일파일.html` |
| 🟡 **참고** | `evidence.json` · `adapter.json` · `INDEX.md` · `FOLLOWUP.md` |
| ⚪ **히스토리 (현재 기준 아님)** | `참고자료/` 전체 |

✅ 패키지 안의 프로토타입은 **화면 구성·CTA·인터랙션의 정본**입니다.
문구 관리 문서에 등록된 화면 기준 SHA-256과 바이트 단위로 일치하는 것을 확인했습니다(`DESIGN.md` §0).

⚠️ `참고자료/`는 **과거 디자인 결정과 콘텐츠 설계 배경**입니다.
신별 콘텐츠·상담 내용·매칭의 현재 기준은 **현재 구현 기준 문서**입니다.

## 옵시디언에 넣기

압축을 풀고 **`토닥토닥 디자인가이드` 폴더째 볼트에 넣으면** 끝입니다.
문서 간 링크(`[[DESIGN]]` 같은)가 같은 폴더 안에서 바로 연결됩니다.

권장 설정: 설정 → **Files & Links → New link format: `relative`**

- `.html`은 옵시디언이 렌더하지 못합니다 → 우클릭 "기본 앱으로 열기"(브라우저)
- `.json`은 코드블록으로만 보입니다 → 수치를 검색할 때 쓰세요

이 패키지는 **스냅샷**입니다. 디자인이 바뀌면 갱신본을 다시 받아 폴더를 덮어써 주세요.

## 문구는 여기서 정의하지 않습니다

버튼명·안내·안전 문구의 정본은 **문구 관리 / Copy Master**입니다.
디자인 가이드에는 **"이 화면에 이 고지가 있는가"** 형태의 점검만 남겨 두었습니다(`checks.md` §문구).
