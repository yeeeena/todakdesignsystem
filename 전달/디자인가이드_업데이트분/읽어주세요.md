# 디자인 가이드 업데이트분 — 적용 방법

피드백 「디자인.md 업데이트 방향」 반영분입니다.
**기존 패키지를 새로 만들지 않았고, 바뀐 파일만 담았습니다.**

## 필수 산출물 2개 (이 폴더 최상단)

| 파일 | 무엇 |
|---|---|
| `DESIGN.md` | **신규.** 디자인 작업 전 가장 먼저 읽는 문서. 현재 기준의 진입점 |
| `FOLLOWUP.md` | **신규.** 기존 파일 중 최신 기준과 맞지 않아 손봐야 할 목록 |

## 기존 파일 교체분 (`기존파일_교체/`)

기존 패키지의 같은 이름 파일을 **덮어쓰면** 됩니다.

| 파일 | 왜 바뀌었나 |
|---|---|
| `checks.md` | 문구 인용을 전부 제거하고 `copy_id` 참조 + safety_locked 19건 매핑표로 교체 |
| `COMPONENTS.md` | 신별 콘텐츠의 "정본" 표기 제거(→ 구현 기준 A/B/02), 화면 맵을 01–16으로 정렬 |
| `INDEX.md` | `DESIGN.md`를 최상단 진입점으로, 자료 3단 구분 반영 |
| `evidence.json` | 문구 관리 문서를 근거(R4)로 추가, 확인된 불일치 반영 |
| `README.md` | `DESIGN.md` 우선 안내 + 자료 3단 구분표 |

## 바뀌지 않은 파일

`RULESET.md` · `tokens.json` · `adapter.json` · `reference-board.html` ·
`토닥토닥_프로토타입_단일파일.html` · `참고자료/` — 기존 것을 그대로 쓰시면 됩니다.

## 가장 먼저 봐주실 것

1. **`DESIGN.md` §0** — 화면 정본 SHA-256 확인 결과. 패키지 프로토타입이 낡은 스냅샷이라는
   전제가 틀렸고, **등록 해시와 바이트 단위로 일치**했습니다.
2. **`DESIGN.md` §7-1** — Copy Master와의 실제 불일치 2건 (09 부적 생성 중).
   문구만 고칠지 로더 연출까지 볼지 판단이 필요합니다.
3. **`FOLLOWUP.md`** — 남은 항목과, 확인으로 해소된 항목.
