# 토닥토닥 사용자 피드백 질문지

> 프로토타입(클릭스루 17화면) **대면 세션용**. 세션당 30~40분 기준.
> 대면 없이 링크만 전달해서 받는 경우 → **`피드백_설문_배포용.md`** 사용.
> 설계 원칙: ① 진술보다 행동을 먼저 묻는다 ② 유도 질문 금지("귀엽죠?" ❌) ③ 감정 강도·워크어라운드 신호를 포착한다 ④ 나중에 주제 분석(태깅→빈도×임팩트)이 가능하도록 개방형 중심.

## 0. 리서치 목표와 가설

이 질문지가 답하려는 핵심 질문 4가지:

| # | 리서치 질문 | 검증할 가설 |
|---|---|---|
| RQ1 | **컨셉**: "토착신이 고민을 해석해준다"는 프레임이 위로가 되는가, 거부감(미신/오컬트/유치함)을 주는가? | 무속 프레임은 진지한 상담 앱보다 심리적 진입장벽이 낮다 |
| RQ2 | **플로우**: 고민 입력 → 상담 결과 → 부적까지의 여정에서 어디서 막히거나 이탈하는가? | 입력(04)과 로딩 대기가 가장 큰 마찰 지점이다 |
| RQ3 | **핵심 가치**: 해석(09) · 작은 실천 제안 · 부적(11) 중 무엇이 "다시 오게 만드는" 가치인가? | 부적은 공유 훅, 실천 제안이 리텐션 훅이다 |
| RQ4 | **공유/재사용**: 부적을 실제로 저장·공유하고 싶은가? 다음에 고민이 생기면 또 오는가? | 부적 이미지가 바이럴 루프의 핵심이다 |

## 1. 스크리닝 / 세그먼트 질문 (세션 시작 전, 3분)

> 목적: 합성 단계에서 응답을 세그먼트별로 교차 분석하기 위한 축. 이름 대신 "20대 후반 · 사주앱 헤비유저"처럼 태깅한다.

1. 최근 한 달 안에, 혼자 끙끙 앓은 고민이 있었나요? 어떤 종류였나요? (관계 / 일·번아웃 / 시작·비교 / 거절 / 감정 기복 / 막막함 — 6신 체계와 매핑)
2. 그때 **실제로** 뭘 했나요? (친구에게 말함 / 검색 / 사주·타로 앱 / AI 챗봇 / 아무것도 안 함)
   - *행동 질문. "뭘 하고 싶었나요"가 아니라 "뭘 했나요"로 묻는다.*
3. 사주·타로·운세 서비스를 써본 적 있나요? 얼마나 자주? 돈을 내 본 적은?
4. AI에게 고민을 말해본 적 있나요? 그때 경험은 어땠나요?

**세그먼트 축 (합성 시 사용)**: 운세 콘텐츠 친숙도(헤비/라이트/무경험) × 고민 대처 방식(발화형/검색형/침묵형)

## 2. 과업 수행 + 화면별 질문 (20분)

> 진행 방식: "최근 실제 고민 하나를 떠올리고, 이 앱으로 처방을 받아보세요"라고 과업만 주고 **개입 없이 관찰**. 아래 관찰 포인트를 먼저 기록하고, 과업이 끝난 뒤 화면별 질문을 한다.

### 관찰 포인트 (질문하지 말고 기록)

- [ ] 02 신 리스트에서 스스로 신을 고르는가, 헤매는가? 어떤 기준으로 고르는가?
- [ ] 04 입력에서 고민을 몇 자나 쓰는가? 쓰다 지우는가? 실제 고민을 쓰는가, 가짜 고민을 쓰는가?
- [ ] 로딩(08/10) 동안 이탈 신호(딴짓, 화면 벗어남)가 있는가?
- [ ] 09 상담 결과를 끝까지 읽는가, 스크롤로 건너뛰는가?
- [ ] 11 부적을 스스로 플립하는가? 힌트 없이 발견하는가?
- [ ] 12에서 저장/공유 버튼을 누르는가? (프로토타입이라도 누르려는 시도 자체가 신호)

### 화면별 질문 (과업 종료 후)

**01~03 진입 · 신 선택**
- 첫 화면을 봤을 때 이 서비스가 뭘 해주는 곳이라고 생각했나요?
- 신을 고를 때 뭘 보고 골랐나요? 내 고민에 맞는 신이 없다고 느낀 순간이 있었나요?
- "토착신"이라는 컨셉을 처음 봤을 때 솔직한 첫 느낌은? (긍정 유도 없이 그대로 받아적기 — RQ1)

**04 고민 입력**
- 고민을 쓸 때 어디까지 솔직하게 썼나요? 덜 쓴 게 있다면 왜인가요?
- 쓰면서 막힌 지점이 있었나요? (빈 입력창 공포 — RQ2)

**08/10 로딩**
- 기다리는 동안 어떤 기분이었나요? 기다림이 "처방을 준비하는 의식"처럼 느껴졌나요, 그냥 로딩이었나요?

**09 상담 결과 (해석 + 작은 실천)**
- 방금 받은 해석을 자기 말로 한 문장 요약해 주세요. (*이해도 확인 — 요약 못 하면 해석이 안 꽂힌 것*)
- 해석 중 "내 얘기다" 싶었던 문장이 있었나요? 반대로 뻔하다/영혼 없다 싶었던 문장은?
- 제안받은 "작은 실천"을 실제로 할 것 같나요? **언제, 어디서 할 것 같은지** 구체적으로 말해 주세요. (*"할 것 같아요"는 진술, 시점·장소를 말하면 행동 의도*)

**11~12 부적 · 저장/공유**
- 부적을 받았을 때 첫 반응은? (표정·감탄사도 기록)
- 이 부적을 **지금 폰에 저장**한다면 어디에 쓸 건가요? (배경화면 / 보관 / 안 함)
- 누군가에게 보여준다면 **누구에게, 어떤 말과 함께** 보낼 건가요? (*"공유하시겠어요?"보다 훨씬 강한 신호 — RQ4*)
- 앞/뒤 플립을 발견했나요? 뒷면 내용은 어땠나요?

## 3. 세션 마무리 종합 질문 (7분)

1. 전체 경험을 겪고 나서, 이 서비스를 친구에게 소개한다면 뭐라고 한 문장으로 말할 건가요? (*사용자 언어로 된 가치 제안 — 카피 소스*)
2. 오늘 경험에서 **하나만 남기고 다 없앤다면** 뭘 남길 건가요? 해석 / 실천 제안 / 부적 / 신 캐릭터 중에서. (RQ3 — 강제 선택)
3. 반대로 **하나를 없앤다면** 뭘 없앨 건가요? 왜?
4. 다음에 진짜 고민이 생기면 이걸 다시 열 것 같나요? 그 고민이 어떤 종류일 때요? (*재사용 조건 특정*)
5. 이런 서비스에 돈을 낸다면 어떤 순간에, 무엇에 낼 것 같나요? (부적 소장판 / 깊은 해석 / 구독) 안 낸다면 왜?
6. 오늘 쓰면서 "이건 좀 아닌데" 싶었지만 말 안 한 게 있나요? (*마지막 안전망 질문 — 의외로 여기서 진짜가 나옴*)

## 4. 정량 설문 (세션 후 or 비대면 배포용, 5점 척도)

> 각 문항은 위 정성 질문과 짝을 이룸. 평균이 아니라 **분포**를 본다 (3.5 평균 = 미지근 vs 호불호 극단, 전혀 다른 이야기).

| # | 문항 | 검증 |
|---|---|---|
| Q1 | 해석이 내 고민을 제대로 짚었다 | RQ1·해석 적중감 |
| Q2 | 토착신 컨셉 때문에 고민을 말하기가 **더 편했다** | RQ1·프레임 효과 |
| Q3 | 제안받은 작은 실천을 이번 주 안에 해볼 생각이 있다 | RQ3·실천 의도 |
| Q4 | 받은 부적을 저장하거나 남에게 보여주고 싶다 | RQ4·공유 의도 |
| Q5 | 다음에 고민이 생기면 다시 쓸 것 같다 | RQ4·재사용 |
| Q6 | 고민 입력부터 부적까지 과정이 번거로웠다 (역문항) | RQ2·마찰 |
| 개방형 A | 가장 좋았던 순간 하나는? | 딜라이트 포인트 |
| 개방형 B | 가장 어색하거나 별로였던 순간 하나는? | 마찰 포인트 |

## 5. 합성(synthesis) 준비 가이드

세션이 5~8개 쌓이면 `/product-management:synthesize-research`에 노트를 넣고 돌린다. 그때를 위해 기록 규칙:

- **한 관찰 = 한 줄**: "P3(운세 헤비·발화형)는 입력 화면에서 두 번 쓰다 지움 — '진짜 고민 쓰기가 좀 그렇다'" 형태로.
- **인용은 그대로**: 요약하지 말고 받아적기. 이름 대신 세그먼트 태그.
- **태그 축**: 화면 번호(01~17) × RQ(1~4) × 감정 강도(강/중/약).
- **우선순위 매트릭스**: 빈도(몇 명이 겪었나) × 임팩트(핵심 여정을 막나) 로 정렬. 5명 중 4명이 걸린 고빈도·고임팩트 이슈가 다음 스프린트 1순위.
- **진술 vs 행동 구분**: "공유하고 싶어요"(진술)보다 "세션 중 실제로 캡처함"(행동)을 상위 증거로.
