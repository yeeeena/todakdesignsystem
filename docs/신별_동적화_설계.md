# 신별 전체 플로우 동적화 — 설계 문서

> 작성일: 2026-07-27

## 1. 목표 & 배경

현재 프로토타입은 결과(09)·부적(11) 등 상담 화면 문구가 **하나의 관계 시나리오(서낭신 테마)로 하드코딩**돼 있다. 어떤 신을 골라도 같은 관계·서운함 카피가 나오고, 부적 화면은 기본 신이 산신인데 문구는 문신 테마여서 데이터가 섞인다.

이 문서는 6신 각각의 **고민 시나리오 전체(입력→반영→정리→결과→부적)**를 신별로 동적화하기 위한 데이터 모델·콘텐츠·매칭 로직을 정의한다. 모든 콘텐츠는 B문서 §10(상담 결과 생성 구조)에서 발췌한 정본이다.

## 2. 담당 영역 교정 (중요)

문서 정본을 적용하면 현재 프로토타입의 신별 담당 영역이 아래처럼 교정된다. 리스트(02)·상세(03)의 서낭신·산신·용왕 카피를 새로 쓴다.

| 신 | 현재(프로토타입) | 문서 정본 담당 | 첫 노출명 |
|---|---|---|---|
| 서낭신 seonang | 관계·서운함·소속감 | **갈림길·이동·선택** (이직/퇴사 결정, 새 환경 적응, 선택 미루기) | 갈림길에 선 사람을 배웅하는 마을 어귀의 지킴이 |
| 문신 munsin | 경계·거절 | 경계·거절·선 긋기·심리적 안전 ✓ | 들일 것과 막을 것을 가르는 문의 수호신 |
| 산신 sansin | 번아웃·중심 | **시험·면접·승진·문턱** | 문턱 앞에 선 사람의 코치 |
| 삼신할미 samsin | 시작·비교 | 새 시작·창작·연애 시작 ✓ | 새로 시작되는 모든 것을 점지해주는 신 |
| 용왕 yongwang | 감정 파도·타이밍 | **기회·돈 흐름·이직·운의 전환·타이밍** | 막힌 흐름을 읽어주는 물의 신 |
| 칠성신 chilseong | 막막함·숨고르기 | 번아웃·회복·수면·방전 ✓ | 밤 12시에만 불이 켜지는 보건실 선생님 |

> 서낭신·산신·용왕이 크게 바뀐다. HANDOFF에서 "팀 확정 필요"였던 3신이 마침 이 3신이며, 이제 정본 문서로 확정된 셈.

## 4. 신별 콘텐츠 (정본 발췌)

각 신의 결과 6단 = B문서 §10-10 결과 카드 전체 예시. 부적 의미 = §10-7(노출). 주의 = §10-8. 추천 = §10-9.

### 4-1. 서낭신 (seonang) — §3 코드 블록 참조 (대표 예시로 위에 전문 기재)

### 4-2. 문신 (munsin)
- **담당**: 경계·거절·선 긋기 · **부적상징**: 문틀·빗장·봉인 인장
- **매칭 키워드**: 거절, 선 넘, 카톡, 부탁, 참, 예민, 불편, 상사, 경계
- **시나리오**: 상사가 퇴근·주말에 사적 카톡. 거절 못 하고, 내가 예민한 건가 싶음.
- **결과 6단**
  1. 한마디: "누가 네 선 넘었네. 말해봐."
  2. 마음의 결: "거절하고 싶은 마음이랑, 상사라서 불이익 걱정되는 마음이 둘 다 있는 거지. 그래서 답장하면서도 계속 찜찜한 거고. 그거 네가 예민한 거 아니야. 업무 시간 끝나고 사적으로 넘어온 건 그쪽이야. 선을 넘은 쪽이 있는데 왜 네가 미안해해."
  3. 고민 이름: "불편한데 '내가 예민한 건가'로 자꾸 삼켜버리는 고민"
  4. 새 문장: "나는 예민한 사람이 아니야. 내 선을 알아보기 시작한 사람이야."
  5. 작은 실천: "다 막을 필요 없어. 오늘은 주말 연락 하나만. 다음 주말에 사적인 카톡 오면 월요일에 답해. '주말엔 확인이 어려워서요' 한 줄이면 돼. 그게 첫 번째 문이야." (steps: 제일 불편한 침입 하나 고르기 / 내 책임인지 상대 몫인지 나누기 / 짧은 거절 문장 하나 준비)
  6. 보조안내: "난 상사를 나쁜 사람으로 판결하지 않아. 그쪽 의도는 몰라. 다만 네가 불편한 건 사실이고, 그 선을 지킬 권리는 너한테 있어."
- **주의**: "이 부적은 상대를 응징하거나 관계를 끊어주는 게 아니에요. 문신은 당신의 경계를 지킬 뿐, 상대를 심판하지 않아요."
- **부적 의미**: "이 부적엔 빗장 하나가 그려져 있어요. 오늘 당신이 닫은 문이에요. 전부 닫으란 게 아니라, 하나를 지켰다는 표시예요."
- **부적 제목(초안)**: "오늘 닫은 문 하나"
- **추천(원문)**: → 우물신(MVP 밖). §7 결정 필요.

### 4-3. 산신 (sansin)
- **담당**: 시험·면접·문턱 · **부적상징**: 능선·지팡이·호랑이
- **매칭 키워드**: 면접, 시험, 발표, 승진, 준비, 망칠, 문턱, 포기
- **시나리오**: 면접 이틀 전, 준비가 하나도 안 된 것 같아 포기하고 싶음.
- **결과 6단**
  1. "…이틀 남았구나. 왔으면 됐어."
  2. "이틀 앞두고 잠도 못 잘 만큼 잘하고 싶은 거잖아. 그 마음이 있으니까 무서운 거야. 그건 준비를 안 해서가 아니야. 지금 너를 누르는 건 '다 못 했다'는 목록이야. 그 목록이 문제지, 네가 부족한 게 아니야."
  3. "정상을 한 번에 오르려다, 첫 발이 안 떼지는 고민"
  4. "나는 준비 안 된 놈이 아니야. 오늘 한 칸 오른 놈이야."
  5. "오늘은 새로운 거 보지 마. 이미 본 것 중에 자꾸 막히는 질문 3개만 골라. 그 3개만 오늘 밤 산이야. 자소서는 덮어. 오늘 할 게 아니야." (steps: 오늘 집중할 것 하나 정하기 / 집중 타이머 50분 / 막히는 것 3개만 적기)
  6. "결과는 내 산 바깥 일이야. 난 붙여줄 수 없어. 넌 오늘 한 칸 오른 거고, 그거면 됐어."
- **주의**: "이 부적은 합격을 보장하지 않아요. 산신은 오르는 과정만 함께해요. 결과는 당신이 만들어가는 거예요."
- **부적 의미**: "이 부적의 능선 3단은 오늘 오른 한 칸이에요. 정상이 아니라 한 칸. 그게 오늘의 기록이에요."
- **부적 제목(초안)**: "오늘 오른 한 칸"
- **추천**: → 칠성신 (MVP 내 ✓): "이 방향이 맞는지 확신이 없다면, 칠성신이 어디로 가고 있는지 같이 봐줄 수 있어요."

### 4-4. 삼신할미 (samsin)
- **담당**: 새 시작·연애 시작 · **부적상징**: 씨앗·보따리·비녀 구슬·실
- **매칭 키워드**: 고백, 썸, 짝사랑, 시작, 새 일, 창작, 도전, 겁나, 어색
- **시나리오**: 동아리 사람 두 달째 짝사랑. 고백했다 어색해질까 봐 망설임.
- **결과 6단**
  1. "어유, 며칠째 잠도 못 잤구나. 그 마음, 할미가 좀 보자."
  2. "한쪽 마음은 분명히 다가가고 싶은데, 다른 한쪽은 지금의 편안한 사이를 잃을까 봐 조심스러운 거지. 두 마음이 다 진심이라 더 잠이 안 오는 거야. 이건 네가 겁이 많아서가 아니란다. 그 자리가 소중하니까 조심스러운 거야."
  3. "좋아하는 마음을 들킬까 봐, 그 마음을 자꾸 작게 접어두는 고민"
  4. "나는 겁이 많아 못 하는 아이가 아니라, 소중한 걸 조심스럽게 심는 중인 거란다."
  5. "오늘 고백할지 말지를 정하지 않아도 돼. 대신 딱 하나만. 그 사람한테 부담 없는 안부 한마디만 보내봐. '오늘 동아리 재밌었어요' 정도면 충분해. 마음을 여는 게 아니라, 문을 살짝 열어두는 거야." (steps: 오늘 할 수 있는 제일 작은 것 하나 / '오늘은 여기까지' 먼저 정하기 / 남과 비교하지 않기 오늘 하루 약속)
  6. "이 결과는 네 마음을 정리해보는 하나의 이야기야. 그 사람의 마음이 어떨지는 할미도 알 수 없어. 그건 만나가면서 천천히 알아가는 거란다."
- **주의**: "이 부적은 결과를 보장하지 않아요. 삼신할미는 탄생의 순간을 지켜줄 뿐, 결과는 당신이 만들어가는 거예요."
- **부적 의미**: "이 부적엔 씨앗 하나가 담겨 있어요. 결과가 아니라, 오늘 시작하기로 한 마음의 표시예요. 씨앗은 작아도 괜찮아요. 작으니까 자랄 일만 남은 거니까."
- **부적 제목(초안)**: "분홍 실이 감긴 씨앗"
- **추천(원문)**: → 우물신(MVP 밖). §7 결정 필요.

### 4-5. 용왕 (yongwang)
- **담당**: 기회·돈·이직 흐름·타이밍 · **부적상징**: 구슬·물결 (부적 = 파문 원/두 갈래 물길)
- **매칭 키워드**: 이직 제안, 기회, 돈, 흐름, 타이밍, 우유부단, 답장 못, 연봉, 제안
- **시나리오**: 이직 제안 왔는데 지금 팀도 좋아 2주째 답장 못 함. 우유부단한 것 같아 답답.
- **결과 6단**
  1. "자— 2주째 답장을 못 하고 있구나. 급할 거 없어."
  2. "가고 싶은 마음도 진짜고, 지금 사람들한테 미안한 마음도 진짜야. 둘 다 진심이라 못 고르는 거지, 우유부단해서가 아니야. 널 붙잡는 건 '결정 못 하는 나'라는 생각이야. 근데 물은 원래 갈림길에서 잠깐 고여."
  3. "두 물길이 다 좋아서, 어느 쪽으로도 노를 못 젓고 있는 고민"
  4. "나는 우유부단한 사람이 아니라, 두 물길을 다 소중히 여기는 사람이야."
  5. "오늘 결정 안 해도 돼. 대신 A4 한 장에 지금 자리에서 얻는 것 3개, 새 자리에서 얻을 것 3개만 적어봐. 답을 고르는 게 아니라, 두 물길을 눈으로 보는 거야." (steps: 시간·에너지 어디로 가는지 적기 / 제일 갉아먹는 것 하나 끊거나 줄이기 / 오래 미뤄온 기회 하나 열기)
  6. "어느 쪽으로 갈지는 내가 못 정해줘. 연봉이나 조건은 데이터랑 같이 봐야 하고. 난 그저 네 흐름이 지금 갈림길에 있다는 걸 보여줄 뿐이야."
- **주의**: "이 부적은 투자나 수익을 보장하지 않아요. 용왕은 흐름을 같이 보는 신이지, 결과를 대신 만들어주는 신이 아니에요. 큰 결정은 데이터와 함께 보세요."
- **부적 의미**: "이 부적의 파문 원은 흐름이 다시 움직이기 시작했다는 표시예요. 막혔던 물이 다시 흐르기 시작할 때 생기는 파문이에요. 한방이 아니라 물처럼 천천히, 그리고 멈추지 않게."
- **부적 제목(초안)**: "다시 흐르기 시작한 물결"
- **추천(원문)**: → 업신(MVP 밖). §7 결정 필요.

### 4-6. 칠성신 (chilseong)
- **담당**: 번아웃·회복·방전 · **부적상징**: 별 7점·궤도 (부적 = 북두칠성 중 별 하나 점등)
- **매칭 키워드**: 방전, 번아웃, 지침, 못 쉬, 무기력, 계속 지쳐, 남들은 다, 잠
- **시나리오**: 몇 주째 지쳐 있고 주말에 쉬어도 월요일이면 방전. 남들은 다 잘 사는데 나만 무너지는 느낌.
- **결과 6단**
  1. "일단 앉아. 요즘 잠은 좀 자?"
  2. "몇 주째 그렇게 지쳐있으면서도 계속 버텨온 거잖아. 그거 약해서가 아니야. 오래 참아온 거야. 지금은 게으른 게 아니라 방전된 거야. 배터리가 0인데 안 켜진다고 자책하는 거랑 똑같아."
  3. "쉬어도 채워지지 않고, 쉬는 것마저 불안한 방전 상태"
  4. "나는 게으른 사람이 아니야. 오래 버텨온 사람이야."
  5. "회복 계획 세우지 마. 그것도 일이야. 오늘 밤 11시에 화면만 꺼. 잠 안 와도 괜찮아, 누워있는 게 회복이야. 딱 그 한 칸만." (steps: 오늘 밤 정해진 시간에 화면 끄고 눕기 / 점심에 10분 눈 감기 / '쉬는 것도 회복 노동' 되뇌기)
  6. "이 방전이 너무 오래가거나 점점 심해지면, 그건 나 혼자 봐줄 수 있는 게 아니야. 그땐 꼭 전문가한테 기대야 해."
- **주의**: "이 부적은 병을 낫게 하지 않아요. 몸에 이상 신호가 계속되면 병원을 먼저 찾으세요. 칠성신은 곁에서 회복을 돕는 자리까지예요."
- **부적 의미**: "이 부적엔 북두칠성 중 별 하나에 불이 켜져 있어요. 완전히 회복됐다는 게 아니라, 오늘 하나를 다시 켰다는 표시예요. 일곱 별은 천천히 켜지는 거예요."
- **부적 제목(초안)**: "오늘 다시 켠 별 하나"
- **추천**: → 문신 (MVP 내 ✓): "자꾸 방전되는 이유가 '거절을 못 해서'라면, 문신이 재발을 막을 선을 세우는 걸 도와줄 수 있어요."

## 5. 고민 → 신 배정 매처

사용자 답변: 기본 신 고정이 아니라 **고민 내용에 따라 배정**. 문서 §6 매칭 기준·§9-1 강매칭 조건·§12-4 고민 패턴표 근거.

```js
function matchDeity(text, emotions) {
  // 1) text 소문자화 후 각 신 matchKeywords 히트 수 카운트
  // 2) emotions(선택 감정칩)로 가중치 보정
  // 3) 최고 점수 신 반환. 동점/무입력 → 'seonang'(기본)
}
```

- **클릭스루 대응**: 입력 화면(04)에 **고민 예시 6개**(각 신 sampleWorry 요약, §4-5 공감문장)를 탭 가능한 칩으로 추가 → 탭하면 textarea 채움 + 곧바로 그 신으로 배정되는 게 데모로 보임.
- 배정 결과는 `appState.selectedDeity`에 저장. 이후 05·07·09·11이 모두 이 값을 읽음.
- 무입력/무매칭 fallback = **서낭신**.

## 7. 결정 필요 / 미해결

1. **다른 신 추천 MVP 정합성** — 문서 원문 추천이 MVP 6신 밖을 가리킴:
   - 문신 → 우물신(없음) · 삼신할미 → 우물신(없음) · 용왕 → 업신(없음)
   - **권장 대체안** (A문서 §3-8 관계선 기준, 추천 문구는 재작성·팀 확정):
     - 문신 → **산신** (동맹: 차단 후 훈련) 또는 추천 생략
     - 삼신할미 → **서낭신** (라우팅) 또는 추천 생략
     - 용왕 → **칠성신** (타이밍 회동: 이직 시점) 또는 추천 생략
   - 대안: 추천 섹션을 MVP 내 대상일 때만 노출(문신·삼신·용왕은 생략).
2. **부적 제목 6종** — 문서에 시적 제목 없음. §4 초안은 Claude 작성 → 팀 확정.
3. **talismanLead/talismanCaution** — 부적 의미·주의에서 파생한 요약. 확정 시 교체.
4. 감정칩·여력 화면은 범용 유지(신별 아님). 향후 매칭 신호로 확장 가능.

## 8. 검증 방법

- 로컬 서버로 `prototype/` 서빙 → 6신 각각 리스트→상세→입력→결과→부적 클릭스루, 문구가 신별로 바뀌는지 확인.
- 고민 예시 칩 탭 → 의도한 신으로 배정되는지 확인.
- 무입력 진입 → 서낭신 fallback 확인.
- 부적 화면 카드 이미지 = 배정 신과 일치(앞/뒤 플립) 확인.
